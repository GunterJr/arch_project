\section{Introduction}
Step 3 was the final step in the Verilog project. In this step, we wrapped the
4-bit ALU operations we made in step 2 inside of a controller. This controller
can take any two arbitary 4-bit numbers, and perform addition, subtraction,
multiplucation, division, or shifting. We will also be using the logic gates
made in the previous section (AND, OR, NAND, etc.) All operations will
be calculated regardless of the requested output; the control code simply
switches to the output of the desired operation.

\subsection{Controller}
For the controller, we take 4 different inputs. A, B, Cin, and OP. A and B are the 2 inputs, Cin is a carry-in bit for add and sub, and OP is the opcode for the controller. It then runs all 12 operations, and then sets the 3 outputs X, Y, and Cout to the operation's results depending on the opcode given.
\lstinputlisting[language=Verilog]{Verilog/alu4.v}
\subsection{Test Bench}
The test bench loads the inputs for the logic operations, and then iterates the opcode between them, testing each circuit. Then it sets the inputs for 2 different tests of the shifter. Then it sets the 3 inputs for add and sub, and then iterates the opcodes, and then does 2 more groups of inputs for mult and div. Then there is one last test for the unused opcode values.
\lstinputlisting[language=Verilog]{Verilog/alu4_tb.v}

\section{Conclusion}

In this step, we successfully created a controller for 4-bit ALU operations.
This could hypothetically be used as the ALU unit for a 4-bit computer given
implementation of other pipeline phases. We used GTKWave to analyze a
couple dozen waveforms to show that our ALU works properly when given
4-bit numbers.

This project step went the smoothest from a workflow perspective. We are
all quite familiar with Verilog and were able to get a working testbench up
fairly quickly. \LaTeX provided a clean way to show our results that we made a
good template for. The hardest part of this assignment was ensuring that the
control character system we made was working properly.

Git was used for collaboration.
